VALORANT COMIC GAME - GITHUB PAGES SETUP

This folder is already organized for your GitHub Pages repository.
The 25 scene images are named scene01.jpg through scene25.jpg in the exact order you sent them.

1. Unzip this folder on your computer.
2. In your GitHub repository, choose Add file > Upload files.
3. Upload index.html AND scene01.jpg through scene25.jpg to the ROOT of the repository (same place as README.md).
4. Commit the changes.
5. Wait about 30-60 seconds, then refresh your GitHub Pages site.

The game includes:
- Your 25 comic images in the exact order you sent them.
- Scene 22 as the marker before Mini Game 1.
- Mini Game 1: 45-second spike defuse. Hold the button about 5 seconds without releasing.
- Scene 23 after completing Mini Game 1.
- Scene 24 as the marker before Mini Game 2.
